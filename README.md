# Roblox modelleri

Oyuna doğrudan eklenebilen, kendi animasyon script'iyle gelen modeller. Asset yüklemesi gerekmez;
her modelin klasöründe kurulum ve ayarlar anlatılır.

| Model | Dosya | Açıklama |
|---|---|---|
| Ateş Ejderhası | [`ejderha/AtesEjderhasi.rbxmx`](ejderha/AtesEjderhasi.rbxmx) | Kanatlı, boynuzlu kızıl ejderha; kanat çırpar, alev püskürterek kükrer. [Ayrıntılar](ejderha/README.md) |
| Lav Dinozoru | [`dinozor/LavDinozoru.rbxmx`](dinozor/LavDinozoru.rbxmx) | Lav çatlaklı, sırtı yanan T-rex; lav damlatır, alev ve lav püskürterek kükrer. [Ayrıntılar](dinozor/README.md) |
| Üç Başlı Ejderha | [`ucbasli/UcBasliEjderha.rbxmx`](ucbasli/UcBasliEjderha.rbxmx) | Altın pullu, üç başlı, iki kuyruklu ejderha; başlar ayrı ayrı hareket eder, ağızlarından altın şimşek çıkararak kükrer. [Ayrıntılar](ucbasli/README.md) |
| Buz Yılanı | [`buzyilani/BuzYilani.rbxmx`](buzyilani/BuzYilani.rbxmx) | Buz tüylü, yerde kıvrılmış dev yılan; dil çıkarır, burnundan buhar çıkar, öne atılıp buz nefesi püskürtür. [Ayrıntılar](buzyilani/README.md) |
| Kristal Anka | [`kristalanka/KristalAnka.rbxmx`](kristalanka/KristalAnka.rbxmx) | Camdan anka kuşu; havada süzülür, kanat çırpar, kurdeleleri dalgalanır, çığlık atınca ışık patlaması saçar. [Ayrıntılar](kristalanka/README.md) |
| Orman Örümceği | [`orumcek/OrmanOrumcegi.rbxmx`](orumcek/OrmanOrumcegi.rbxmx) | Desenli karınlı yeşil dev örümcek; ayakları yere basılı kalır, bacak kaldırır, dişlerini tıkırdatır, şahlanıp zehir püskürtür. [Ayrıntılar](orumcek/README.md) |

Studio'da: Explorer → **Workspace**'e sağ tık → **Insert from File...** → `.rbxmx` dosyasını seçin, sonra **Play**.
